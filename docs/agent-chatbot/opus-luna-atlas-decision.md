# Opus 5.5 產品決定 — Luna 與 Atlas

2026-10-03，以 Claude CLI `claude-opus-5-5`、medium 執行產品決策。以下為輸出；沒有把審批權交給代理。

# NGOPilot × Atlas 统一 UX 决策（PM 定稿）

## 0. 不变项
保留原 Agent 运行时、会话历史、工具卡、人工确认和产物下载。四个 MCP 工作流与 Scheduler 各自独立，**只改视觉层和模型接入层**，不改工具逻辑。

## 1. 全局视觉
- 背景 `#f6f8f6`，面板纯白，描边 `1px #dfe7e2`。**去掉米色。**
- 主文字 `#193b34`，次要文字 `#5e746b`，主色 `#126455`，选中/悬停底色 `#e9f2ed`。
- 焦点环统一用 `2px #946414`（amber），只用于 focus，不当装饰色。
- 字体 DM Sans + Noto Sans TC，正文 15px，卡片标题 16/600，页面标题 22/600。
- 圆角：输入框、按钮 8px，卡片 10px，chip 7px。
- 所有可点元素 ≥44px，过渡统一 160ms ease-out。

## 2. 顶栏（72px）
- 左：NGOPilot 标识 + 当前会话名。
- 右：模型状态胶囊（`gpt-6-luna · 已连接/未配置`）+ 设置。
- **删除大时钟。** 时间只在 Scheduler 卡片和消息时间戳里出现。

## 3. 侧栏（宽 280px，白底）
从上到下：
1. 「新对话」主按钮，teal 实心，44px。
2. **工作流**：四个 MCP 工作流 + Scheduler，共五行。每行 44px，左侧图标，右侧状态点。点击后在输入框预填该工作流的引导语，不跳页。
3. **历史会话**：按「今天 / 本周 / 更早」分组。当前项用 `#e9f2ed` 底色加左侧 3px teal 条。
4. 底部：设置、模型配置入口。

## 4. 首页（空会话）
- 居中最大宽度 760px。标题「今天要处理什么？」，下一行副标题用 muted 色。
- 五张工作流卡片，2+3 栅格（大屏 3 列）。每张 ≥96px 高，包含图标、名称和一句话用途。**取消现有小 chips。**
- 输入框固定在底部：白底、10px 圆角、上传图片按钮、发送按钮（44px）。

## 5. 聊天内工具卡
- 白卡片 + 描边，头部依次为：工具名、工作流标签 chip、状态。状态取值为运行中 / 待确认 / 完成 / 失败。
- 正文分两部分：参数摘要默认展开最多 3 行；原始输入/输出折叠。
- **人工确认**：卡片底部是 amber 细描边的提示区，写明「将执行：…」，配两个按钮「确认执行」（teal 实心）和「取消」（描边）。确认前不发送任何调用。
- **产物下载**：每行显示文件图标、文件名、大小和下载按钮（44px）。多个文件时追加「全部下载」。
- Scheduler 卡片额外显示下次运行时间和启用开关。

## 6. 模型接入
- 所有文本与图像调用统一走 Foundry `gpt-6-luna` deployment。配置项为 endpoint、deployment 名、API key，key 只放在服务端环境变量里。
- 不声称 Luna 支持音频。

## 7. API Key 为空时
- 应用正常启动。历史、侧栏、工作流卡片都能浏览，历史产物可以下载。
- 顶栏胶囊显示「模型未配置」，amber 描边。
- 首页输入框上方放一条横幅：「尚未配置 Foundry gpt-6-luna API Key，暂时无法发起对话。」右侧是「前往配置」按钮，后台只说明需要配置的环境变量名，**不在前端收集或回显 key**。
- 发送按钮禁用，悬停时提示原因。
- 不显示任何虚假或示例回复，也不降级到其他模型。
- 若服务端返回 401/404（key 或 deployment 不对），在消息流中显示错误卡片，给出原因和「重试」。

## 8. 音频（默认方案，用户未回复即执行）
- 只接受文字稿：支持粘贴文本或上传 .txt/.docx。
- 移除旧的 ASR 调用和录音入口。界面不出现麦克风图标。
- 如果用户后续另开 Foundry Speech，作为独立可选适配器接入，不改动现有工作流。

## 9. 验收
- 五个入口都能在首页和侧栏一键进入。
- 确认流程键盘可达，焦点环可见。
- 文字对比度 ≥ WCAG AA。
- 无 key 时零模型请求、无报错白屏。
- 截图对比 Atlas 时，色值、圆角、头部高度一致。

## 工程落實

採用原 Chatbot 入口、Atlas 白底綠色、側欄、五個提示入口、人工核對及未配置狀態。Scheduler 是活動日曆工具，並非定時自動化服務，因此沒有實作建議中的定時開關／下一次運行等虛構操作。批量下載與取消作業未列入本輪驗收。使用者已決定停用語音服務，改用轉寫文本。
