# CareFlow Pilot 视觉决策（对齐 Atlas 现行 theme-atlas.css）

**冲突裁定：** Atlas 的强调色是赭红 #7d3b27，不是绿色。我们按"使用精确 token"执行，弃用绿色，不另造色值。确认、通过类状态改用墨色实心加 ✓ 符号表达。

**Token：** 直接沿用 Atlas，不新增。
- 底色 paper #f7f4ec，卡片 card #fffdf8，正文 ink #1d2622
- 次要文字 mute #7a766b，分隔线 rule #ddd6c6，弱底 soft #efe8da，强调 accent #7d3b27
- 标题用 Noto Serif TC 600/700，界面用 Inter
- 圆角 2–3px；不用阴影、渐变和图标卡

**桌面端（≥1024px）**
- **顶栏：** 52px，左侧衬线字标"CareFlow Pilot"，右侧放账户。下方 1px rule 分隔。
- **左栏：** 240px（原 280px），只放原有对话历史。条目为衬线标题加 mute 日期，选中项为 soft 底加 2px accent 左边线。
- **主区：** Agent 对话，正文最大宽 720px，居中。
  - 用户消息：card 底，1px rule 边框。
  - Agent 回复：无框正文，段落之间用细线分隔。
- **工具审核卡：** 保留在消息流内。card 底，1px rule 边框，顶部一行小号大写标签（如"审核 · 排班"）。主按钮为 accent 实心，次按钮为文字链接。
- **输入框（最高优先级）：** 固定在底部，宽度与正文一致。card 底，1px ink 边框，高 ≥96px，发送按钮为 accent 实心。
- **工具索引：** 仅在空会话时出现在输入框上方，标题为"可用工具"。五行 dotted index，每行依次是：编号 01–05、衬线工具名、点线引导、右侧 mute 一句用途。点击后只把示例 prompt 填入输入框，不自动发送。开始对话后折叠为输入框上方一行 mute 文字链接"工具索引"。

**移动端（<768px）**
- 顶栏 52px：汉堡按钮打开对话历史抽屉（全屏，paper 底），中间放字标。
- 对话全宽，左右边距 16px。
- 输入框吸底，适配安全区，最小高 56px，聚焦时展开。
- 工具索引在空会话时显示为同样的编号列表。去掉点线引导，用途说明换到第二行。
- 审核卡全宽，按钮纵向堆叠，主按钮在上。

**明确删除**
- 绿色图标卡
- 大时钟
- 任何统计数字、进度环、"今日效率"类伪指标
- 装饰插画
- 工具独立页面入口：工具不进入导航，只作为 prompt 建议

**字级**
- 对话标题：衬线 22/28
- 正文：Inter 15/24
- 索引名：衬线 16
- 元数据：Inter 12，颜色 mute

**说明：** 以上对齐的是 atlas-photo-intake 工作树中的现行 token，不对 Atlas 整体视觉做"完全一致"的承诺。

## 實作取捨

使用現行 Atlas worktree 的 theme-atlas.css，而非主目錄舊 sans-serif 版本。首頁輸入框置於索引之前，讓對話成為第一操作；對話頁仍沿用原本底部輸入框。保留既有模型設定入口，沒有虛構帳戶介面。側欄移除重複的五工具入口，保留歷史對話。
